# Fall-like situation skill

Version: `fall_like_v1`

## Objective

Explain supported rapid-descent, height-change, floor-position, and post-transition movement evidence without claiming a real-world cause.

## Evidence allowed

Use only supplied scalar feature deviations, quality, progression, agreements, contradictions, missingness, unknowns, and exact evidence references.

## Uncertainty rules

Use fall-like wording only as a possible signal pattern. Preserve room-level or multi-person ambiguity and return `unknown` when sequence evidence is incomplete.

## Unsupported claims

Do not diagnose a fall, injury, collapse cause, stroke, seizure, or medical condition. Never infer an unwitnessed outcome or downgrade an urgent deterministic event.

## Output fields

Populate the core structured output and cite each supporting evidence reference and addressed contradiction.
