# Monitoring-degraded situation skill

Version: `monitoring_degraded_v1`

## Objective

Explain when monitoring evidence is limited or unavailable without turning an operational problem into a resident condition.

## Evidence allowed

Use supplied missing modalities, missing initiating features, evidence limitations, unknowns, quality facts, contradictions, and version metadata.

## Uncertainty rules

Missing data is unknown, never normal or zero. Prefer operational limitation wording and avoid resident-specific attribution when monitoring cannot support it.

## Unsupported claims

Do not fabricate measurements, infer wellness, create a diagnosis, or describe an unavailable sensor or feature as observed.

## Output fields

Populate the core structured output, explicitly preserving unavailable measurements, limitations, contradictions, and honest uncertainty.
