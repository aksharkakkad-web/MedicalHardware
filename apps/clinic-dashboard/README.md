# Clinic Dashboard

This Next.js application is the frontend foundation for the clinic product.

Install dependencies and start the local development server with pnpm:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) and edit
`src/app/page.tsx` to update the initial page.

## Commands

```bash
pnpm dev        # Start the development server
pnpm lint       # Run ESLint
pnpm typecheck  # Check TypeScript without emitting files
pnpm test       # Run the Vitest test suite
pnpm build      # Create a production build
```

The bootstrap configures Vitest, but does not include behavior tests yet.
