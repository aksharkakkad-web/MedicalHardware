| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Trusting vendor docs over the wire | The brief and library both describe framing/pins that do not match the hardware. Cost: would have produced a parser that never synced. | blocking | Sniff raw bytes and cycle candidate pin pairs first; require a checksum to validate before declaring a format |
| Plausible-looking fabricated vitals | Radar emitted 117–119 bpm from furniture. A naive integration pipes that to a caregiver dashboard. | blocking | Frozen-distance detection in the aiming build; in M8, gate vitals on the module's own `invalid` marker plus a liveness check |
